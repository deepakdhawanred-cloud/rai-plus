# Quick Revise: Study Games (v2)

438 picture-based revision games for Classes 6–12, organised **class → subject → chapter**.

## What's inside

| Class | Book followed | Chapters covered | Games |
|---|---|---|---|
| 6 | Science: Curiosity · Maths: by topic · English | All 12 Science chapters | 48 |
| 7 | Science: Curiosity · Maths: by topic · English | All 12 Science chapters | 40 |
| 8 | Science: Curiosity · Maths: by topic | All 13 Science chapters | 39 |
| 9 | Science: **Exploration (new, 2026-27)** · Maths: by topic | All 13 Science chapters | 46 |
| 10 | Science: NCERT (rationalised) · Maths · Social Science | All 13 Science chapters | 55 |
| 11 | Physics · Chemistry · Biology (NCERT rationalised) | All 14 + 9 + 19 chapters | 111 |
| 12 | Physics · Chemistry · Biology (NCERT rationalised) | All 14 + 10 + 13 chapters | 100 |

Each chapter has **2–5 games** covering its main topics. "Play whole chapter" runs them back to back.

## The 8 game types

| Type | On screen | Use it for |
|---|---|---|
| `platter` 🍽️ | Drag only the right items onto a plate/tray | "Pick all the X" (food groups, acids, autotrophs) |
| `bins` 🗂️ | One card at a time → throw into the right bin | Classifying (2–5 groups) |
| `sequence` 🔗 | Build a chain in order | Processes, cycles, orders, ladders |
| `label` 🏷️ | Drag names onto a diagram | Cell, atom, flower, eye, neuron, plant |
| `pairs` 🃏 | Memory flip, match two cards | Term ↔ meaning, cause ↔ effect, formula |
| `odd` 🎯 | Tap the one that doesn't belong | Quick concept checks |
| `swipe` 👆 | Swipe a card right (fact) or left (myth) | Busting common misconceptions |
| `gaps` 🧩 | Tap words into blanks | Definitions, formulas, key lines |

Wrong answers always show the one-line fix. Each game ends with stars, XP and a short "Remember" recap.

```
├── src/
│   ├── index.html      page shell (loads the files below)
│   ├── styles.css      design
│   ├── core.js         loader, diagrams, drawing helpers

```

You can host either `dist/quick-revision-games.html` (simplest) or the whole `src/` folder.

## Adding or editing a chapter (no coding)

Open `src/data/class-N.js`. Each chapter is one block:

```js
QR.add({cls:7, subject:'Science', ch:3, chapter:'Electricity: Circuits and their Components', games:[
  { ...game 1... },
  { ...game 2... }
]});
```
For Maths/English chapters with no number, leave out `ch` and give `icon:'🔢'` instead.

Every game has `title`, `icon`, `type`, and optionally `ideas:['🔋|Short recap line', ...]`.

Each line of content uses **`|`** to separate its parts. Never type `|` inside the text itself.

### bins
```js
{title:'Litmus Lab', icon:'🧪', type:'bins',
 bins:['a|🔴|Acidic|blue litmus → red', 'b|🔵|Basic|red litmus → blue'],   // id | icon | label | small text
 items:['a|🍋|Lemon juice', 'b|🧼|Soap|optional tip shown after answering', 'a||HCl']}  // bin | emoji | name | tip
```
Leave the emoji empty (`'a||HCl'`) to show big text instead, e.g. for formulas and words.

### platter
```js
{title:'Build the Plate', icon:'🍽️', type:'platter', serve:'Serve',
 tags:{carb:'Carbohydrate', protein:'Protein'},
 items:['🍚|Rice|carb', '🥛|Milk|protein|fat'],     // emoji | name | tags | "also" tags (left out of that round)
 rounds:['carb|⚡|Carbohydrates|Fill the plate · energy foods|Quick energy.']}  // tag | icon | title | hint | idea
```

### sequence
```js
{title:'Water Cycle', icon:'🌧️', type:'sequence', prompt:'Follow a water drop', hint:'optional',
 items:['☀️|Sun heats water|small label', '💨|Evaporation', ...],   // write in the CORRECT order
 reveal:'🔄|Water cycle|One-line takeaway'}
```

### pairs
```js
{title:'Missing Nutrient', icon:'🩺', type:'pairs',
 pairs:[ ['🥕|Vitamin A', '👁️|Poor eyesight'], ['|sin 30°', '|1/2'] ]}   // 3–6 pairs works best
```

### odd
```js
{title:'Odd One Out', icon:'🎯', type:'odd', rounds:[
  ['🌵|Cactus', '🐪|Camel', '🦎|Lizard', '*🐧|Penguin', 'Why: 🐧 lives in cold'] ]}   // * marks the odd one; last = reason
```

### swipe
```js
{title:'Magnet Truths', icon:'🧭', type:'swipe', cards:[
  'T|Every magnet has two poles',
  'F|Like poles attract|Like poles repel'          // F = myth; 3rd part = the correction
]}
```

### gaps
```js
{title:'Food Test Lab', icon:'🧪', type:'gaps', extra:['optional', 'distractor words'],
 lines:['🍚 Iodine turns starch [blue-black].', '1 m = [100] cm']}   // [brackets] = blanks
```
Wrong-answer choices are taken from the other lines' answers. Make sure no two lines could swap answers.

### label
```js
{title:'Label the Eye', icon:'👁️', type:'label', svg:'eye',
 spots:[ [112,182,'Cornea','🪟','lets light in'], ... ]}    // x, y (on a 400×300 picture), name, emoji, function
```
Ready-made diagrams: `plantCell`, `animalCell`, `plant`, `flower`, `atom`, `eye`, `neuron`.
To use your own picture: `svg:'<image href="/img/heart.png" width="400" height="300"/>'` plus `w:400, h:300`.

### Your own photos
Anywhere an item appears, you can use `{img:'/images/rice.jpg', n:'Rice', bin:'a'}` instead of the short text form.

**Safety check:** if a game's content is malformed, that one game is skipped (with a warning in the browser console). The rest keep working.

## Connecting to your website / Student 360°

```html
<iframe src="/games/quick-revision-games.html?class=9&subject=Science" style="width:100%;height:100vh;border:0"></iframe>
```
URL options: `?class=9`, `&subject=Biology`, or `?game=<id>` to open one game directly (IDs look like `c9-science-2-1`: class 9, Science, chapter 2, game 1).

When a game ends, the page sends this to your site:
```js
window.addEventListener('message', e => {
  if (e.data?.source !== 'vis-quick-revision') return;
  // { type:'game-complete', gameId, cls, subject, chapterNo, chapter, gameType, title,
  //   accuracy, stars, xp, hits, misses, bestCombo, timeSec }
});
```
Save it per student and you get chapter-wise weak-topic reports for teachers (low accuracy on a chapter means re-teach it).

Game IDs come from each game's position in its chapter. If you insert a game in the middle of a chapter, later IDs shift. To keep saved stars stable, give important games a fixed `id:'my-unique-id'`.

Progress (stars, XP, streak) is also saved on the device (`localStorage`, key `vis-quickrev-v2`).
