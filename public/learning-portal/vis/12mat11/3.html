Direction

l = cos α, m = cos β, n = cos γ

l² + m² + n² = 1

l = a / √(a² + b² + c²)

Through P, Q: DRs x₂ − x₁, y₂ − y₁, z₂ − z₁

Line

Vector: r = a + λb

Cartesian: (x − x₁)/a = (y − y₁)/b = (z − z₁)/c

Two points: r = a + λ(b − a)

Angle

cos θ = |b₁·b₂| / (|b₁||b₂|)

⊥ : a₁a₂ + b₁b₂ + c₁c₂ = 0

∥ : a₁/a₂ = b₁/b₂ = c₁/c₂
